# tiecar

**tiecar** (Theory of Information Encoding, Compression and ARchiving) — мощная библиотека на Java для создания, кодирования и декодирования различных помехоустойчивых кодов.

В основе библиотеки лежит проект **galois**, реализующий работу с конечными полями различной мощности и поддерживающий основные алгебраические операции.

На данный момент в tiecar реализованы:

- Коды Рида-Соломона — классический метод исправления ошибок,
- Два кодека: стандартный и на основе преобразования Фурье–Мэттсона–Соломона (ФМС-преобразования), обеспечивающий альтернативный способ кодирования и декодирования.


## Цели проекта

- Предоставить гибкую и расширяемую платформу для работы с помехоустойчивым кодированием,
- Обеспечить удобные инструменты для исследователей и разработчиков в области теории кодирования,
- Поддерживать расширение за счёт добавления новых кодеков и методов работы с конечными полями.
